Sona 0.6.2 Preview · build 11

适用于 macOS 26 或更高版本的 Apple Silicon Mac。

### 更新

- **应用 × 设备独立音量**：选中应用的输出设备后，分别调节各路音量。重新选择设备可恢复之前的音量，并支持迁移旧版偏好。
- **更自然的界面过渡**：设备切换、设备行增减和面板高度变化采用连贯缓动，已有设备行保持稳定；响应系统“减少动态效果”设置。
- **修复顶部跳动**：逐应用选择或取消输出设备时，顶部声音模块保持稳定，避免文字、滑块和边缘短暂偏移。
- 设备按钮使用中性透明玻璃、蓝色选中图标，统一不同设备图标的尺寸与留白。
- 改善音量拖动期间的后台写入与服务重连后的配置恢复，清理重复设计资源和安装包中的 macOS 扩展元数据。

### 下载与升级

下载 **Sona-0.6.2.pkg**。完整安装包包含 App、HAL 驱动及 Sona Audio Service；新增独立音量需要同时更新 App 和服务，请使用完整安装包升级。

安装需要管理员权限，会短暂重启系统音频并中断播放。**这是预览版：二进制采用 ad-hoc 签名，安装包未使用 Developer ID 签名，也未经过 Apple 公证。** 如 macOS 阻止打开，请到「系统设置 → 隐私与安全性」选择「仍要打开」。

使用本页的校验文件验证下载：

```sh
shasum -a 256 -c Sona-0.6.2.pkg.sha256
```

选中多个设备可同时输出；**取消全部设备即让该应用无输出**。明确选择的设备断开时，不会自动把声音送回默认扬声器。旧服务不能提供各路独立音量，对应控件会禁用，需一并升级服务。

安装、诊断与卸载见[使用指南](https://github.com/FfszHy/Sona/blob/v0.6.2/docs/BUILDING.md)。
